# Tomnest

Compagnon pour League of Legends : fiches champions détaillées, builds et runes, patch notes et carte illustrée de Runeterra.

**Plateformes** : Windows et Android · **Version actuelle** : 0.11.0 (bêta)

> Ce dépôt ne contient que les téléchargements et le guide d'installation, pas le code source.

## Télécharger

Les installeurs sont disponibles dans la page [Releases](../../releases).

| Plateforme | Fichier |
| --- | --- |
| Windows | `Tomevale.Setup.0.11.0.exe` |
| Android | `Tomevale-0.11.0.apk` |

> Le nom « Tomevale » dans les fichiers de cette version est l'ancien nom de l'application. Les prochaines versions porteront le nom Tomnest.

## Installation

### Windows

1. Télécharge l'installeur `.exe`.
2. Lance-le. Windows affiche « Windows a protégé votre ordinateur », car l'installeur n'est pas encore signé : clique sur **Informations complémentaires**, puis **Exécuter quand même**.
3. Choisis le dossier d'installation, puis lance Tomnest depuis le menu Démarrer.

### Android

1. Télécharge le fichier `.apk` directement sur ton téléphone.
2. Ouvre-le et autorise l'installation depuis cette source quand Android le demande.
3. Lance Tomnest.

## Compte et synchronisation (facultatif)

Sans compte, tout reste sur ton appareil. Tu peux transférer tes données d'un appareil à l'autre avec un QR code ou un code texte.

Avec un compte, créé dans **Paramètres**, tes favoris, champions possédés, skins et builds se synchronisent sur tous tes appareils. Tu peux supprimer ton compte et tes données à tout moment depuis les Paramètres.
